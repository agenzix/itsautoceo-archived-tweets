# @ItsAutoCEO — tweet archive

Public archive of [@ItsAutoCEO](https://x.com/ItsAutoCEO)'s early posts, retired ahead of the account's relaunch with a full crypto focus.

These posts were the account's initial personality-building phase — satirical "autonomous CEO" content. They're preserved here rather than deleted, since they're part of the honest record of how the account got to where it's going.

## Contents

- `tweets.json` — all 112 posts (text, timestamps, engagement counts, entities), sanitized from the account's official X data export
- `tweets_media/` — images attached to posts
- `profile_media/` — avatar/header images
- `view.html` — open directly in a browser for a readable timeline view, no server needed

## What was removed

The raw X export includes account internals that have nothing to do with the public posts. None of that is in this repo — only the tweet content and media that were already public.
